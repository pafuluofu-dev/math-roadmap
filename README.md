# Маршрут: математика

Трекер повторения математики к переаттестации: темы 1–24 первого семестра «Математики» (РУТ (МИИТ), программа 2026) до возвращения из академотпуска 9 февраля 2027. Одностраничник на React с хэш-роутером, прогресс хранится в браузере; формулы рендерит KaTeX.

**Сайт:** https://pafuluofu-dev.github.io/math-roadmap/

## Разделы

- `#/` — обзор: обратный отсчёт, общий прогресс, карточки блоков, «Сегодня», «К повтору сегодня», «Разница», «Формат занятия», экспорт/импорт;
- `#/plan` — весь план: блоки → недели → занятия с галочками; в резервных неделях можно добавлять занятия «второго круга»;
- `#/checks` — проверки и пробные экзамены: у каждой свои задания с ответами для самопроверки (ответ открывается по кнопке, автопроверки нет), запись результата (порог 80 %) и журнал ошибок с повторами через 3 и 14 дней;
- `#/theory` — чек-лист теории: 35 вопросов, тумблер «не знаю / формулировка / могу объяснить»;
- `#/formulas` — шпаргалка: формулы по темам 1–24 с поиском; `#/formulas/12` открывает двенадцатую тему.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (сначала проверка типов, потом Vite). Превью сборки: `npm run preview`.

## Как редактировать план

Весь контент лежит в `src/data/` обычными TS-объектами, без CMS:

- `plan.ts` — блоки, недели, занятия (даты, названия, минуты) и фиксированные события резерва;
- `checks.ts` — список проверок и пробных экзаменов, формат и порог;
- `theory.ts` — вопросы теории по трём группам;
- `testBank.ts` — задания и ответы для каждой проверки; связь с `checks.ts` по `checkId`, мини-проверки привязаны к `MINI_CHECK_DATES` по порядку;
- `formulas.ts` — формулы по темам 1–24 для раздела «Формулы»; LaTeX записывается через `String.raw`, инлайн-математика в тексте — `$...$`;
- `difference.ts` — секция «Разница» и текст «Формат занятия»;
- `resources.ts` — учебники и материалы.

Формулы рендерит [KaTeX](https://katex.org/) (`katex` в `dependencies`). Все строки с LaTeX статические, из `src/data/`; пользовательский ввод через KaTeX не проходит.

## Хранение и перенос

Галочки, результаты проверок, теория, журнал ошибок и занятия второго круга лежат в `localStorage` под одним ключом `math-roadmap:v1` (тема — отдельно). Синхронизации между устройствами нет: на обзоре есть «Экспорт» (скачивает JSON-файл) и «Импорт» (читает файл и заменяет состояние после подтверждения). При смене схемы данных ключ версионируется с миграцией, прогресс не стирается.

## Деплой

GitHub Pages через Actions (`.github/workflows/deploy.yml`): собирается `dist/` с `--base=/math-roadmap/` и публикуется артефактом. На Pages выкладывается только сборка — исходники напрямую не подключаются.
